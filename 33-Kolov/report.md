## Организация проекта

Исходный код расположен в `src/main/java/ru/bmstu/lab1`.
Для каждого решения выделен отдельный пакет `task_1`–`task_15`.

Автоматические тесты расположены в `src/test/java/ru/bmstu/lab1`.
Каждому классу решения соответствует тестовый класс:
`Task1Test`, `Task2Test`, …, `Task15Test`.

Markdown-файлы с описанием решений и расчётами сложности находятся
в пакетах рядом с исходным кодом.

В качестве основной структуры данных используется целочисленный массив.
Он соответствует входным данным заданий, обеспечивает доступ
к элементу по индексу за O(1) и позволяет последовательно обрабатывать
элементы. Для сортировок порядок элементов изменяется согласно
требованиям конкретного задания.
