# Задача 10. Индекс последнего кратного элемента

## Обозначения

`n` — число элементов массива, `2 ≤ n ≤ 99999`. Оценки даны для допустимого входа. Операции с `int` и `long` считаются постоянными по времени. O обозначает верхнюю оценку, Θ — точный порядок роста. Оценка описывает зависимость от n, несмотря на заданный предел размера.

## Идея решения

При ненулевом k массив просматривается справа налево. Возвращается индекс первого найденного при таком просмотре элемента, кратного k; иначе −1.

## Временная сложность метода

Если ответ имеет индекс p, проверяется n − p элементов. Лучший случай — Θ(1), когда последний элемент кратен k. Худший — Θ(n), когда совпадений нет или единственное совпадение находится в начале. При равновероятном положении единственного совпадения среднее время — Θ(n). Проверка k на ноль занимает Θ(1).

## Пространственная сложность

Дополнительные переменные занимают Θ(1) памяти.

Исходный массив занимает Θ(n). Общая память программы с учётом входного массива — Θ(n).

## Ввод и вывод

Считывание n чисел требует Θ(n) времени при фиксированной разрядности int. Вывод результата при заданных ограничениях занимает Θ(1). Поэтому даже при Θ(1) времени самого поиска полная программа с чтением массива работает за Θ(n).

## Ручные тесты

Индексы начинаются с нуля. Перед массивом при запуске main вводится его длина; дополнительные параметры передаются в порядке, установленном кодом main.

```text
[3, 4, 6, 5], k = 3 → 2
[1, 0], k = 7 → 1
[1, 5], k = 2 → -1
```
