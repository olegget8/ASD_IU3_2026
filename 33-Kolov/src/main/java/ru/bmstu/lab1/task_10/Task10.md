# Задача 15. Пузырьковая сортировка с подсчётом обменов

## Обозначения

`n` — число элементов массива, `2 ≤ n ≤ 99999`. Оценки даны для допустимого входа. Операции с `int` и `long` считаются постоянными по времени. O обозначает верхнюю оценку, Θ — точный порядок роста. Оценка описывает зависимость от n, несмотря на заданный предел размера.

## Идея решения

Соседние элементы меняются местами, если нарушают порядок по неубыванию. После прохода правый конец сокращается. При отсутствии обменов сортировка завершается досрочно.

## Временная сложность метода

В худшем случае выполняется (n − 1) + … + 1 = n(n − 1) / 2 сравнений: Θ(n²). На уже отсортированном массиве первый проход выполняет n − 1 сравнений без обменов, после чего срабатывает досрочный выход: Θ(n). Для случайной перестановки различных элементов среднее время — Θ(n²). Число обменов равно числу инверсий и не превышает n(n − 1) / 2.

## Пространственная сложность

Индексы, временная переменная, флаг swapped и счётчик long занимают Θ(1) дополнительной памяти. long нужен, поскольку число обменов при допустимых n может превысить Integer.MAX_VALUE.

Исходный массив занимает Θ(n). Общая память программы с учётом входного массива — Θ(n).

## Ввод и вывод

Считывание n чисел требует Θ(n) времени при фиксированной разрядности int. Вывод массива содержит не более n чисел и занимает O(n). Поэтому ввод и вывод не увеличивают приведённую основную оценку времени; для линейного метода полное время также Θ(n).

## Ручные тесты

Индексы начинаются с нуля. Перед массивом при запуске main вводится его длина; дополнительные параметры передаются в порядке, установленном кодом main.

```text
[3, 2, 1] → [1, 2, 3], обменов 3
[1, 2, 3] → [1, 2, 3], обменов 0
[2, 2, 1] → [1, 2, 2], обменов 2
```
