# Задача 28. Медиана массива

## Обозначения

`n` — число элементов массива, `2 ≤ n ≤ 99999`. Оценки даны для допустимого входа. Операции с `int` и `long` считаются постоянными по времени. O обозначает верхнюю оценку, Θ — точный порядок роста. Оценка описывает зависимость от n, несмотря на заданный предел размера.

## Идея решения

Создаётся копия массива и сортируется Arrays.sort(int[]). При нечётной длине возвращается центральный элемент; при чётной — среднее двух центральных.

## Временная сложность метода

Копирование занимает Θ(n). После сортировки выбор одного или двух элементов занимает Θ(1). Поэтому T(n) = Θ(n) + Tsort(n). Для обычной оценки используемой сортировки примитивного массива средняя сложность составляет O(n log n); средняя сложность метода также O(n log n). Точная оценка худшего случая зависит от реализации Arrays.sort(int[]) в используемой версии JDK: из одного вызова библиотеки её вывести нельзя. Для варианта быстрой сортировки без защиты от плохих разбиений худший случай O(n²); при гарантированной библиотечной оценке O(n log n) эта же оценка относится ко всему методу.

## Пространственная сложность

Копия int[] требует Θ(n) памяти. С учётом рабочего пространства стандартной сортировки общая дополнительная память метода — O(n), а из-за обязательной копии — Θ(n). Исходный массив сохраняется. Приведение к long до сложения двух центральных элементов предотвращает переполнение; деление на 2.0 сохраняет половину единицы.

Исходный массив занимает Θ(n). Общая память программы с учётом входного массива — Θ(n).

## Ввод и вывод

Считывание n чисел требует Θ(n) времени при фиксированной разрядности int. Вывод результата при заданных ограничениях занимает Θ(1). Поэтому ввод и вывод не увеличивают приведённую основную оценку времени; для линейного метода полное время также Θ(n).

## Ручные тесты

Индексы начинаются с нуля. Перед массивом при запуске main вводится его длина; дополнительные параметры передаются в порядке, установленном кодом main.

```text
[8, 1, 5, 3, 9] → 5.0
[8, 1, 5, 2] → 3.5
[-2147483648, 2147483647] → -0.5
```
